# Поиск пробелов в наблюдении за SSH-сессиями

Black Arachne ищет пару эпизодов с противоположными подтверждёнными исходами и одинаковой видимой телеметрией. Такая пара показывает, что для вынесения разных решений данных в выбранном представлении недостаточно. Отчёт содержит идентификаторы эпизодов, контрольную сумму общей последовательности и результаты проверки по каждому источнику. Пару можно воспроизвести при следующем изменении сбора данных.

## Как воспроизвести

```sh
python3 -m arachne observe-gaps arachne/data/trial.jsonl --max-checks 1
python3 -m arachne observe-gaps arachne/data/trial.jsonl --tolerate-missing 1
python3 -m arachne observe-gaps discovery.jsonl --holdout unseen.jsonl --max-checks 2
```

В открытом синтетическом наборе обнаружены три пары. Существующая проверка заявки различает одну. Две пары остаются без явного различающего сигнала. При недоступности одного источника текущая телеметрия не обеспечивает устойчивого различения ни одной пары.

## Что проверяется

- Совпадение вычисляется по типам событий, относительному времени и отметке входа. Абсолютные даты, имена хостов и учётных записей, идентификаторы событий и результаты дополнительных проверок не входят в представление. При наличии идентификатора сеанса проверяется его принадлежность. Записи с итогом `review` исключаются из поиска пар.
- Источник считается различающим, когда он дал явное подтверждение в одном эпизоде и явное возражение в другом. Отсутствие данных и противоречивые сведения оставляют пару открытой. Признак различимости показывает, что наблюдения отличаются, и сам по себе не определяет вердикт.
- Поиск максимизирует число различимых пар в пределах бюджета, затем выбирает наименьшее число источников. Отчёт также показывает результат каждого фиксированного источника и эффект отключения каждого источника из выбранного набора. Каждый источник имеет одинаковую условную стоимость.
- При `--tolerate-missing 1` пара требует двух разных источников, каждый из которых по отдельности даёт явное различие. Это моделирует недоступность одного источника. Независимость отказов проверяется отдельно на стенде.
- Отложенная выборка оценивается с набором источников, зафиксированным по первой выборке. Семейства и идентификаторы эпизодов должны различаться. Количество отличающихся пар зависит от состава выборки, поэтому его следует публиковать вместе с числом эпизодов и распределением по семействам.

## Как проверить новый сигнал

В строку лабораторного JSONL можно добавить поле `signals` с результатами независимого измерения. Например, `"signals": {"session_attestation": "supports"}`. Источник в данном случае подтверждает, что заявленная личность привязана к конкретному сеансу. Допустимы `supports`, `disputes`, `unknown` и `conflict`. Используйте одно имя на независимый источник и получайте его состояние отдельно от разметки исхода. Отсутствие поля означает неизвестное состояние. Для лаборатории доступны до шести дополнительных источников и до 256 эпизодов на выборку.

Команда читает подготовленные файлы локально. Доверие к источнику и его аппаратная либо криптографическая привязка устанавливаются за пределами этого эксперимента. Для лабораторного сравнения сигналов, которые предложили сами агенты, есть отдельная команда. [Методика эксперимента с агентами](signal-experiment.md)

Поиск пар с одинаковыми наблюдениями известен в формальной диагностике. Исследовательский вопрос Black Arachne — сможет ли смена ролей помогать выбирать различающие сигналы для новых инцидентов при равном бюджете по сравнению с фиксированными правилами и одиночным агентом. Текущая команда даёт воспроизводимую проверку для такого сравнения. [Формальная проверка различимости](https://ijcai.org/proceedings/2003/54)
