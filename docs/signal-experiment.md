# Как Red и Blue предлагают недостающую улику

```sh
python3 -m arachne compare-signals arachne/data/signal-discovery.jsonl arachne/data/signal-holdout.jsonl
```

Каждый агент получает четыре признака видимой SSH-сессии. Blue выбирает, какое подтверждение важнее для версии о штатной работе. Red независимо выбирает, какая проверка могла бы её оспорить. После обмена предварительными предположениями каждый агент принимает предположение другого и может предложить дополнительное условие, которое свяжет две версии с одной наблюдаемой записью.

При наличии заявки Blue может предложить проверить, покрывает ли она сеанс. Red может предположить, что важнее подтвердить личность. После обмена агенты могут запросить составное подтверждение, связывающее одобренную заявку и подтверждённого оператора с одним сеансом. В словаре эксперимента это `identity_change_session`. Оно требует собственной записи от независимого источника. Отдельные записи о личности и заявке не заменяют связанную запись.

## Как проходит сравнение

- Калибровочные эпизоды нужны для выбора лучшего фиксированного сигнала и разрешения разногласий между предложениями. Идентификаторы эпизодов и семейства в отложенной выборке отличаются. Агенты получают только четыре признака и, в нужной фазе, краткий результат предыдущего предложения. Метки и измерения остаются у оценщика.
- Планы формируются для всех профилей отложенной выборки до поиска пар с противоположными исходами. Отчёт сохраняет контрольную сумму планов и результаты для каждой пары.
- Четыре варианта получают по одному подготовленному измерению на пару. Фиксированный вариант выбирает лучший источник на калибровке. Одиночный агент получает второй раунд и может сам предложить составную улику. Два независимых агента действуют без обмена в отдельном варианте. Бюджет относится к использованию готовой записи. Стоимость её создания и полная стоимость работы агентов остаются за рамками текущего прогона.
- Успех означает, что выбранное измерение подтверждает штатную версию в закрытом эпизоде и оспаривает её в другом. Обратный результат отмечается отдельно. Отсутствующие, противоречивые и одинаковые показания оставляют пару нерешённой.

## Первый воспроизводимый результат

Четыре калибровочные и восемь отложенных пар синтетические. Отложенная выборка закрыта для агентов во время прогона. Оба файла опубликованы для воспроизводимости.

| Вариант | Верно различил | Оставил открытыми | Указал в обратную сторону |
|---|---:|---:|---:|
| Фиксированный источник | 2 | 6 | 0 |
| Один агент с повторной проверкой | 5 | 3 | 0 |
| Два агента без обмена | 3 | 5 | 0 |
| Два агента со сменой ролей | 4 | 3 | 1 |

Смена ролей сгенерировала составную улику `identity_change_session`, для которой на калибровке не было измерений. В одном отложенном случае она дала правильный результат, а одиночный агент оставил дело открытым. В другом случае синтетический источник той же улики указал в обратную сторону. Одиночный агент выиграл сравнение по общему числу правильно различённых пар.

По умолчанию эксперимент работает в отдельных локальных процессах с фиксированной схемой для шести допустимых требований. Внешнюю модель можно подключить явно через `--model` и переменную `OPENAI_API_KEY`. Интеграция проверена подставным ответом модели. Данные пилотного журнала, клиенты и работающие источники телеметрии в этот эксперимент не подключались.
